部署教學（3 分鐘）
Vercel：到 vercel.com → New Project → 上傳這個檔案 → Deploy → 拿到 https://xxx.vercel.app 就完成。
GitHub Pages：開一個 Repo → 上傳這個檔案改名 index.html → Settings → Pages → Deploy from main → 拿到 https://你的帳號.github.io/xxx/ 就完成。
學校主機：把檔案用 FTP 上傳到學校主機，網址就是 https://學校網域/chem.html，QR-Code 會自動用那個網址。
注意：純靜態版沒有共用資料庫。老師和學生在不同手機上，名單不會自動同步到老師手機。學生簽到成功後會顯示成功畫面與簽到碼，老師可現場核對，或搭配下一版 Firebase / Google 試算表版做到即時同步。如需即時同步版請告訴我。
